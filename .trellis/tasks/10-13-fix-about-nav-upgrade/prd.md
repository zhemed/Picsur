# 修「关于」侧栏项对齐 + 用面板自升级真实升级

## 背景

0.7.0 给设置页加了「关于」入口（`/settings/about`），但侧栏里这一项的图标/文字与其它项**未对齐**
（截图中明显偏低）。上一轮只做了功能验证，没做视觉审查。

## 需求

1. **修对齐**：让「关于」与「常规 / API 密钥 / ShareX / 用户 / 角色 / 系统设置」完全同款
   （同一套容器结构、同样的图标尺寸与行高、文案基线与图标垂直居中一致）。
2. 顺带**自查侧栏其它项**是否有同类问题（间距/图标尺寸/选中态）。
3. 修完发 **0.7.1**（版本号四处同步 + tag → CI 发镜像）。
4. **端到端验证自升级**：在常驻实例上开启自升级（挂 docker.sock + `PICSUR_ALLOW_SELF_UPDATE=true`），
   用「关于」页/接口把实例从 0.7.0 升到 **0.7.1**，确认：升级后 `/api/info` = 0.7.1、
   数据（图片/用户）完好、「关于」项对齐正确、升级状态显示成功。

## 验收标准

- [ ] AC1 `bw` 截图 + `eval` 量测：「关于」项与其它的图标/文字**同基线**（给出量测数值，不靠肉眼）。
- [ ] AC2 三包构建通过；审计 0。
- [ ] AC3 版本号 0.7.1 四处同步；tag `v0.7.1` 推送后 CI 成功发布 `:v0.7.1`（及 `:latest`/`:allinone`）。
- [ ] AC4 常驻实例经**面板自升级**从 0.7.0 升到 0.7.1（真实链路，不是手动 docker 命令）。
- [ ] AC5 升级后数据完好（既有图片可取回）、`/api/info`=0.7.1、对齐修复可见。
- [ ] AC6 自升级的**开启状态**如何处置（保持开启 / 恢复默认关闭）在报告里明确说明并征询。
