# README 部署命令折行，避免代码块横向滚动

## 背景

用户对比 `zhemed/komari` 的 README，指出我们的部署命令在 GitHub 上超出代码块宽度、出现横向滚动条。

## 需求

1. 把 `docker run` 按参照物风格**反斜杠折行**（每行 ≤ 80 字符），命令语义**完全不变**。
2. 顺带核对 README 其余代码块/段落是否有同样问题（`install.sh` 那条、`pnpm`/`curl` 等）。
3. 不改任何命令内容与文档结构。

## 验收标准

- [ ] AC1 折行后的命令**逐 token 等价**于原命令（去掉 `\` + 换行后再比对字符串一致）。
- [ ] AC2 每条命令**行宽 ≤ 80**；整体 README 行数变化 ≤ 5 行。
- [ ] AC3 折行后的命令**实际可执行**：`docker run` 那条在本机跑通到 `/api/info` 200（端口 8093，不碰常驻栈）。
- [ ] AC4 提交带 `[task:10-13-readme-wrap-command]` 锚点并 push。
