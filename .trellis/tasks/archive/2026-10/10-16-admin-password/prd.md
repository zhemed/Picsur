# admin 密码无法在 UI 修改

## 现象

- 「编辑用户 admin」填入新密码 → **无效** ✗（截图 ✓）；
- 同页提示**未走 i18n** ✗（英文原文 ✓）。

## 疑似根因（待实测）

去角色化那轮把 admin 设为"只读"✓ 时，可能在 `POST /api/user/update` 上**整体拒绝 admin** ✗，而该接口**同时负责改密码** ✓ → 权限确实该挡 ✓，密码不该挡 ✗。

## 要求

1. 实测复现：用 admin 的 token 调 `POST /api/user/update`（只改 password ✓ / 只改 permissions ✗）各一次，记录状态码与消息 ✓；
2. 修：**只挡权限编辑**、**放行密码修改** ✓（并给明确错误消息 ✓）；前端：admin 页的密码输入框应可用 ✓、提示文案走 i18n ✓；
3. 回归：加断言（admin 改密码 → 成功；admin 改权限 → 被拒 + 明确消息）✓；
4. 验收：UI 上真的能改 admin 密码（改完能用新密码登录 ✓）、提示为中文 ✓、三包构建 + 回归全绿 ✓。
